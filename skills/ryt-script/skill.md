# RYT-Script: Ragnar YouTube Script Skill

## Purpose
Generate YouTube video scripts in Ragnar Pitla's voice using a proven structure: 3 shifts, real examples, numbered frameworks, tiered takeaways, one sticky closing phrase.

## Script Structure

### 1. Opening Hook (30-60 seconds)
- Start with a provocative claim or observation
- Make it personal: "I keep seeing..." or "Here's what I realized..."
- Create tension: identify a gap, contradiction, or problem
- End hook with: "So... now what?" or "Here's what changed."

### 2. Three Shifts (Core Content)
Structure the main content as **exactly 3 numbered shifts**:

```
### Shift 1: [The Old Way]
What everyone thinks/does now. The status quo.

### Shift 2: [The Breaking Point]
Why the old way doesn't work anymore. Real examples with specifics.

### Shift 3: [The New Reality]
What actually works. Your framework or approach.
```

Each shift should include:
- A clear, bold statement
- A real example with specific numbers (e.g., "50,000 lines across 50 repos")
- A "right?" checkpoint to keep viewers engaged
- A framework or list when explaining concepts (3-5 items)

### 3. Framework Section
When explaining methodology, use numbered lists:
- "Five things you need..."
- "Three tiers of..."
- "Four key changes..."

Be specific about counts. Never say "several" or "many."

### 4. Tiered Actionables
End with advice segmented by audience level:

```
### If You're Just Starting
[Beginner-friendly first step]

### If You're Further Along
[Intermediate tactical advice]

### At the Enterprise/Team Level
[Strategic organizational guidance]
```

### 5. Sticky Close
End with ONE memorable phrase that captures the entire video:
- "Skills compound. Prompts don't."
- "Nobody's buying demos."
- "That's not a product. That's a hope."

This phrase should be quotable, tweetable, and summarize the core insight.

## Voice Guidelines

**Do:**
- Use "right?" as a verbal checkpoint
- Say "Here's the thing..." before key insights
- Reference real people/companies by name (e.g., "Texas Paintbrush on X")
- Use numbers and specifics over vague claims
- Speak in frameworks and tiers
- Be direct: "I'm not going to sit here and tell you..."
- Admit what you're still learning

**Don't:**
- Use em dashes (use commas or periods instead)
- Say "Certainly!" or "Great question!" or other AI cliches
- Be preachy or lecture-y
- Use vague qualifiers ("many," "several," "various")
- Overcomplicate the structure
