Policy
TableOne row per rule, versioned, owned by the business
●Change control
A rule change is a row edit with an author and a date, not a prompt rewrite nobody reviewed.
who changed it, and when
●Explainability
The answer cites the rule that produced it. "The model decided" stops being an acceptable sentence.
rule id on every output
●Testability
Rules are rows, so a regression suite is a query. You can prove today matches last quarter.
golden set runs on merge
●Ownership
Finance owns tolerances. Procurement owns vendor limits. Neither files a ticket to change them.
no engineer in the loop
●Refusal
No matching rule is a real answer. The agent abstains instead of inventing a plausible tolerance.
abstain beats guessing
●Cost
Most requests resolve against a row and never reach a model. The bill stops tracking volume.
flat at 10x load
