# In Our AI Era — Prompt Templates

All prompts start with this style anchor:
```
Flat editorial illustration in bold outline style. Warm cream background #FFF8F0. 
Primary accent coral-red #D93A52. Bold navy outlines #1A1A2E throughout. 
No gradients. No drop shadows. No 3D. Clean flat 2D illustration.
```

## Template 1: Architecture Diagram (Brand Style)

**Use:** Agent architecture, system flows, multi-agent hierarchies

```
Flat editorial illustration in bold outline style. Warm cream background #FFF8F0. 
Primary accent coral-red #D93A52. Bold navy outlines #1A1A2E throughout. 
No gradients. No 3D. Clean flat 2D.
Decorative outlined 6-point stars scattered around composition.

ARCHITECTURE LAYOUT — top to bottom hierarchy:

[TOP NODE — INSERT MAIN AGENT/SYSTEM NAME]
Large rounded rectangle. Coral-red fill #D93A52. White bold text label. 
Bold navy outline 4px. Small robot/gear icon inside left.

[MIDDLE NODES — INSERT CONNECTED/CHILD AGENTS]
Medium rounded rectangles. Dark navy fill #1A1A2E. White text.
Arrow connections: thick rounded arrows, coral-red, with pill-badge labels.

[BOTTOM NODES — INSERT TOOLS/MCPs/INTEGRATIONS]
Smaller rounded rectangles. Light sky fill #D6EEFF. Navy text #1A1A2E.
Dashed arrow connections indicating async/tool calls.

[CHILD AGENTS if any]
Smallest boxes. Soft pink fill #F5A8B8. Navy text. "Child" pill badge.

Label style: bold sans-serif, all caps for node names, sentence case for subtitles.
Arrows: thick, rounded corners, with small arrowheads. Labeled with short pill badges.
Decorative: 3-4 outlined stars in corners. Dot clusters at edges.
Overall feel: illustrated editorial tech diagram, warm and approachable, not corporate.
```

## Quick Prompting Checklist

Before finalizing any prompt, verify:
- [ ] Style anchor included (flat, bold outlines, cream background)
- [ ] Colors reference hex codes (#D93A52 coral, #1A1A2E navy, #FFF8F0 cream)
- [ ] Character specs match reference if characters appear
- [ ] Node types have correct color mapping (orchestrator=coral, tools=light sky, etc.)
- [ ] Decorative elements mentioned (stars, dot clusters)
- [ ] "No gradients, no 3D, no drop shadows" explicitly stated
- [ ] Text labels in quotes with "bold sans-serif" instruction
- [ ] Aspect ratio matches use case
- [ ] Model selected: Nano Banana Pro (characters) or GPT Image 1.5 (text-heavy arch)
