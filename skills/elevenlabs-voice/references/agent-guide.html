2. Where the key is used

  1. The local agent supplies the task and file paths.
  2. elevenlabs-voice reads the current user's saved Keychain item into memory.
  3. The official SDK authenticates the requested HTTPS operation with ElevenLabs.
  4. The helper returns safe status and writes versioned audio and a receipt when generation succeeds.

The guide and global instructions contain the credential's lookup location, never its value. Providing this HTML does not grant access or change permissions.

Credential location

Keychain service rbuild-elevenlabs, account equal to the current macOS username. Use the helper; do not extract the value manually into a shell, notebook, or tool response.

Voice is a separate setting

The user's confirmed voice lives in private local configuration. A saved API key does not select a voice, establish ownership, or authorize a stock voice to be called "my voice."

Prevent an inherited key from winning

The generic helper checks ELEVENLABS_API_KEY before Keychain. The shared-Mac command removes that override from the child process only. It does not change the parent shell or the saved key.

Generic invocation

An inherited environment value can override Keychain.
"$HOME/.local/bin/elevenlabs-voice" doctor

Use the saved Mac key

Invocation change only. The credential loader is unchanged.
env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" doctor

If the user explicitly requests a different environment credential, honor that request instead of silently clearing it. Never dump environment values to inspect precedence.

3. Start a task safely

  1. Read the skill and run the local diagnostic

    The absolute launcher works from any project without activating a virtual environment. This diagnostic does not call ElevenLabs or generate audio.

    Agent / local Terminal - no provider request
    env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" doctor

    Read every result separately. credential=OK means reuse the key even if voice_config fails. A nonzero exit is not automatically a missing-key error.

  2. Use a confirmed saved voice

    If a voice is already configured, reuse it. Otherwise discover the available voices, then have the user select and confirm one in a real Terminal. Do not put a voice ID in the prompt or this guide.

    Discovery - read-only provider request
    env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" voices
    User's Terminal - interactive selection and consent
    env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" configure-voice

    The helper does not clone voices or upload training samples. If no suitable saved voice exists, the user must set one up separately in ElevenLabs. For a voice-config error other than voice_not_configured, stop and report the exact code; do not delete or rewrite private configuration to bypass it.

  3. Discover a current model and run preflight

    Use tts for a script and sts for an existing audio take. These commands are non-generative. Replace the model placeholder with an ID returned for that capability.

    Text-to-speech discovery and preflight
    env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" models --capability tts
env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" status --mode tts --model MODEL_ID_FROM_MODELS
    Speech-to-speech discovery and preflight
    env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" models --capability sts
env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" status --mode sts --model MODEL_ID_FROM_MODELS

    Preflight checks the model, subscription access, voice discovery, and configured voice. Read access passing does not prove permission to call a paid generation endpoint.

4. Generate only the requested audio

Paid operation. Do not run these examples just because you loaded the skill or this page. The user must request the audio. Replace every placeholder and path, use a confirmed voice, and prefer a short audition before a long take.

Script to speech

TTS example - requires an explicit audio request
env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" tts \
  --script /absolute/path/script.txt \
  --output /absolute/path/narration-v001.mp3 \
  --receipt /absolute/path/narration-v001.receipt.json \
  --model MODEL_ID_FROM_MODELS \
  --output-format mp3_44100_128 \
  --purpose audition \
  --confirm-paid-request

Existing audio to the saved voice

STS example - requires an explicit audio request
env -u ELEVENLABS_API_KEY "$HOME/.local/bin/elevenlabs-voice" sts \
  --audio /absolute/path/source-take.wav \
  --output /absolute/path/voice-candidate-v001.mp3 \
  --receipt /absolute/path/voice-candidate-v001.receipt.json \
  --model MODEL_ID_FROM_MODELS \
  --output-format mp3_44100_128 \
  --purpose candidate \
  --confirm-paid-request

The MP3 format is an example supported by the installed SDK contract. Use current provider documentation for other encoded formats. Keep output and receipt names versioned, such as v001, and never overwrite an earlier take.

Keep the evidence with the audio

The helper measures the encoded file and writes a receipt on success. It uses a hashed voice reference rather than a raw voice ID. Failed generation must not leave a completed-looking output and receipt.

Do not replace video blindly

Speech-to-speech can change timing. Compare the new speech with the script, check numbers and identifiers, and measure word or beat boundaries. The receipt marks ASR matching and video retiming NOT RUN. If no accepted alignment check is available, retain the approved video and mark alignment unverified.

Preserve source scripts, audio, and approved videos. Use the existing video engine for timeline changes. Sharing the key also shares its permissions and limits; coordinate long jobs rather than launching unrequested parallel batches. Do not retry a paid call automatically.

5. Diagnose the actual failure

This is a runbook, not a declaration that the account is ready. Check the live result when working on a requested audio task.

ResultWhat it meansNext action
credential=OKThe helper found a locally recognized key.Reuse it. This alone does not prove provider permissions or a configured voice.
missing_keyNo usable configured credential was found.Have the user run save-key in a private Terminal. Never request the key in chat.
credential_lookup_failedKeychain access failed; the item may still exist.Resolve the normal access or unlock prompt. Do not replace the key or weaken access controls as a workaround.
unrecognized_key_formatThe stored value failed the local format guard. Nothing was sent.Confirm the value or current provider format privately. Do not print it for diagnosis.
authentication_failedThe provider rejected authentication.Check validity, expiry, or revocation privately. This is different from a named permission failure.
missing_permissionsThe key lacks a scope; this can be HTTP 401.Ask the user or account administrator to enable only the needed scope; the helper has no permission-grant command. voices_read is voice discovery; user_read is subscription preflight. Generation also needs access to Text to Speech or Voice Changer for the chosen mode.
voice_not_configuredNo confirmed saved voice is selected.Use voices, then user-driven configure-voice. Do not use a documentation example ID.
output_existsA target version already exists.Choose a new version. Do not delete an earlier output to get past the guard.
quota_or_rate_limitThe provider refused the request under a limit.Stop and inspect current usage or limits. Check whether a failed request was charged before another attempt.
Missing model, stream, or audio-probe failureThe requested operation or returned audio did not satisfy the helper's contract.Keep the source and error evidence. Resolve the cause before another versioned request; do not claim success.
